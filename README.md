# AI Workplace Productivity Assistant

## Project Overview

The **AI Workplace Productivity Assistant** is a responsive web application designed to help professionals automate everyday workplace tasks using artificial intelligence.

The application provides three productivity tools for generating professional emails, summarising meeting notes, and organising tasks. Users can provide their own instructions, review the generated content, and edit outputs before using them.

The project focuses on improving workplace efficiency through structured prompts, editable outputs, a user-friendly interface, and responsible AI practices.

## Features Implemented

### 1. Smart Email Generator

- Generates professional emails based on user instructions.
- Supports Formal, Friendly, and Persuasive tones.
- Allows users to select an intended audience.
- Accepts the purpose of the email and optional key points.
- Provides editable generated content.
- Allows users to copy the generated email.

### 2. Meeting Notes Summarizer

- Summarises meeting notes into structured content.
- Identifies key decisions and discussion points.
- Extracts action items, owners, and deadlines where provided.
- Highlights open questions and missing information.
- Provides editable summaries for review and reuse.

### 3. AI Task Planner

- Organises tasks based on deadlines and available working hours.
- Generates a proposed daily schedule.
- Allocates time to individual tasks.
- Provides task prioritisation guidance.
- Identifies scheduling considerations and potential time constraints.
- Allows users to edit the generated plan.

## Setup Instructions

### Prerequisites

Ensure that the following tools are installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/CindyM33/ai-productivity-assistant.git
```

### 2. Navigate to the Project Directory

```bash
cd ai-productivity-assistant
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in the terminal to access the application.

### 5. Build the Application

To create a production build, run:

```bash
npm run build
```

## Usage

1. Open the application dashboard.
2. Select **Email Generator** to create a professional email.
3. Select **Notes Summarizer** to summarise meeting notes and extract action items.
4. Select **Task Planner** to organise tasks and create a proposed schedule.
5. Review and edit generated outputs before using them.

## Responsible AI

AI-generated content may contain inaccuracies or incomplete information. Users should review and verify outputs before relying on them for workplace decisions.

Avoid entering confidential or sensitive workplace information unless the service has been approved for that data by your organisation.

The application is intended to support human productivity and judgement, not replace them.
